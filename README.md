# Dmitry Kazakov — Psychosomatic Therapy

Website for a psychosomatic therapist's online practice.

## Highlights

- **Hebrew-first with right-to-left (RTL) layout**, with Russian language alternates.
- Static frontend: HTML, CSS and vanilla JavaScript — no frameworks.
- Booking page, credentials page and a small content admin panel.
- Deployed as a static site (Hostinger).

## Structure

- `index.html` — main landing page (Hebrew, RTL).
- `booking.html` — appointment booking page.
- `credentials.html` — diplomas and certifications.
- `admin.html` + `assets/js/admin.js` — content admin panel.
- `assets/` — styles, scripts, icons and images.
